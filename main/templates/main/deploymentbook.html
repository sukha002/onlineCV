03

Resolving Git Synchronization

If Git rejects a push with a non-fast-forward error, the remote repository contains commits that are not present in the local repository.

Pull Remote Changes 

git pull origin main --no-rebase

If Git reports conflicts, resolve them before committing the changes.

Push Again 

git push origin main
Important: Do not use git push --force for this deployment workflow.

Preparing Django for Azure

Azure requires a production WSGI server to run the Django application.

Install Gunicorn 

pip install gunicorn

Make sure Gunicorn is included in requirements.txt.

Django WSGI Module onlineCV.wsgi

Verify Django 

python manage.py check
05

Static Files and WhiteNoise

During deployment, the Django HTML may load while CSS and JavaScript return 404 errors.

This normally means Django's static files have not been configured or collected correctly.

STATIC_URL 

STATIC_URL = '/static/'

STATIC_ROOT 

STATIC_ROOT = BASE_DIR / 'staticfiles'

Install WhiteNoise 

pip install whitenoise

Add WhiteNoise to requirements.txt.

WhiteNoise Middleware 

whitenoise.middleware.WhiteNoiseMiddleware

WhiteNoise should be placed immediately after Django's SecurityMiddleware.

Collect Static Files 

python manage.py collectstatic --noinput
Static files should be successfully collected before deployment.

Final Django Check 

python manage.py check

Connecting GitHub to Azure

Azure App Service can automatically deploy new versions from your GitHub repository.

Deployment Center

  1. Open Azure App Service.
  2. Open Deployment Center.
  3. Select GitHub as the source.
  4. Select repository: sukha002/onlineCV
  5. Select the main branch.
  6. Configure GitHub Actions.
  7. Save the deployment configuration.
  8. Check the deployment logs.
Deployment status should show Success.
08

Gunicorn Startup Configuration

If Azure displays the default Python page instead of your Django portfolio, the application startup command needs to be configured.

Azure Configuration

App Service → Configuration → General settings

Startup Command 

gunicorn --bind=0.0.0.0 --timeout 600 onlineCV.wsgi

Save the configuration and allow Azure to restart the application.

After restarting Azure, test the default Azure hostname and the /about/ route.

  • JavaScript does not load.
  • Azure shows the default Python page.
  • Django reports DisallowedHost.
  • GitHub Actions deployment fails.
  • Azure returns a server error.

Custom Domain and HTTPS

Configure the custom domain only after the Azure default hostname is working correctly.

Production Domain

sukhwindertoor.com
www.sukhwindertoor.com

DNS Configuration

Azure will provide the DNS verification records required for your domain.

Do not remove or replace DNS records blindly. Verify each value supplied by Azure before making changes.

HTTPS

After domain verification:

  1. Configure HTTPS/TLS.
  2. Verify the SSL certificate.
  3. Enable HTTPS Only.
  4. Test both HTTP and HTTPS.
